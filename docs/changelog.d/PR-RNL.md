- **Beschriftungen nachgezogen (PR-RNL, 28.11.2026).** Im Systemstatus heißen die Liste „Offene Klärungsfälle“ und die Zeile „Prozessform“, eine alte MECM-Skriptversion erscheint als „Alte Skriptversion: Ergebnis nicht bestätigt“. Der Befund einer VM sagt „Paketinstallation fehlgeschlagen“, der Link zur vollständigen Chronik „Chronik öffnen“. Die Hilfe zitiert die neuen Wörter. Der Abschluss verwaister VMs heißt auch im Audit-Protokoll so, die Endzustände im Bild der Auftragszustände heißen „Abgeschlossen“. Die Verteilhinweise im Autoimporter-Fazit nennen den nächsten Blick in die MECM-Konsole.
