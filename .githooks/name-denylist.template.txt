# VirtuSphere Namensliste (privat). NIE in ein Repo legen oder committen.
# Ablage: $HOME/.config/virtusphere/name-denylist.txt
# (anderer Ort: Umgebungsvariable VIRTUSPHERE_NAME_DENYLIST)
#
# Eine Zeile je Eintrag. Leerzeilen und Zeilen mit '#' am Anfang zaehlen nicht.
# Vergleich ohne Gross-/Kleinschreibung als feste Zeichenkette (Teilstring).
# Praefix "word:" verlangt ein ganzes Wort: kein Buchstabe, keine Ziffer und
# kein '_' direkt davor oder danach (sinnvoll fuer kurze Codes und IPs, damit
# eine IP nicht jede laengere mit gleichem Anfang trifft).
#
# Hierher gehoeren Servernamen, FQDNs und Domainteile, Prod-IPs, DP-Namen,
# Site-Code, echte MACs sowie VM- und Rolloutnamen aus Prod.
#
# Beispiele (synthetisch, nicht eintragen):
#   srv-a.example.test
#   example.test
#   word:192.0.2.10
#   word:XY1
#
# Pruefen: sh scripts/check-name-denylist.sh --check-list
