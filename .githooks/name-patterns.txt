# Freigaben nur fuer Werte, deren synthetische oder oeffentliche Herkunft im
# Repo belegt ist. Keine pauschale Freigabe privater Bereiche (10/8, 172.16/12,

# an die Koordination melden. Neue Tests nehmen Dokumentationswerte
# (192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24, example.test,
# 00:00:5E:00:53:xx) statt einer neuen Freigabe.

# Ein Oktett (0-255) ausgeschrieben, weil Muster keine Variablen kennen:
#   (25[0-5]|2[0-4][0-9]|1[0-9][0-9]|[1-9]?[0-9])

# --- UNC-Pfade --------------------------------------------------------------

# zwei Zeichen (sonst traefen Escapes wie \\r\n).
